================================================================================
                        TROUBLESHOOTING
================================================================================

If npm install still fails:
    npm config set legacy-peer-deps true
    npm install

If you see "Project incompatible with Expo Go":
    - Make sure Expo Go is version 57+
    - Or reinstall: Play Store → Expo Go → Update

If app still shows SDK 53:
    - Your cached node_modules might be old
    - Run: npm cache clean --force && npm install

If "metro bundler" takes too long:
    - Press Ctrl+C
    - Run: npm start --clear
