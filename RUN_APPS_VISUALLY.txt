================================================================================
                      TROUBLESHOOTING - QUICK FIXES
================================================================================

PROBLEM: "npm: command not found"
SOLUTION: Install Node.js from nodejs.org, restart terminal

PROBLEM: "Port already in use"
SOLUTION: expo start --port 8085

PROBLEM: App is blank screen
SOLUTION: Press 'r' to reload, or do:
          npm cache clean --force && npm install

PROBLEM: QR code won't scan
SOLUTION: Copy URL from terminal → paste in Expo Go instead

PROBLEM: App crashes on load
SOLUTION: expo prebuild --clean

PROBLEM: "Cannot find module"
SOLUTION: npm install && expo prebuild --clean

PROBLEM: Emulator connection refused
SOLUTION: Make sure emulator is running, or use physical device
